# Adding Posts Page

A React frontend for listing posts, opening an individual post, and creating new posts. It uses React Router and connects to the companion Express API in the `Backend` repository.

## Requirements

- Node.js and npm
- The `Backend` API running on `http://localhost:8080`

## Run

Start the backend first, then run this frontend:

```bash
npm install
npm run dev
```

Open the local URL printed by Vite in your browser.
